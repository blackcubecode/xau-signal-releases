XAU Signal Bot Telegram — Releases
Repo ini berisi rilis resmi XAU Signal Bot Telegram yang siap diunduh oleh pembeli.
📥 Download Versi Terbaru
Buka tab Releases di repo ini, lalu unduh file `xau\_signal-bot-vX.X.tar.gz` terbaru.
🔑 Setelah Download
Extract paket:
```bash
   tar -xzf xau\_signal-bot-vX.X.tar.gz
   cd xau\_signal
   ```
Ikuti panduan instalasi di `README.md` di dalam paket.
Isi file `.env` dengan nilai berikut:
`TELEGRAM\_BOT\_TOKEN` — token bot dari @BotFather
`TELEGRAM\_CHAT\_ID` — ID chat Telegram Anda. Anda dapat memeriksa ID melalui @userinfobot
`XAU\_LICENSE\_KEY` — kunci lisensi dari penjual (dikirim secara terpisah)
Jalankan bot:
```bash
   python telegram\_bot.py
   ```
